Techniques used by the top seed
The attack layers ~6 distinct techniques. The first two are the engine; the rest are cover and compliance pressure.
1. Seed-quote demotion - the harmful line is quoted once, then explicitly downgraded. The request the classifier scores is a fiction task; the harmful string is framed as inert input.
2. Isomorphic domain transposition (the core, and the novel part) - This is structure-preserving transfer: the order of operations, ratios, and dependencies survive; only the nouns move. The uplift rides across in the preserved sequence, not in any named content.
3. Source/domain suppression - Deletes exactly the tokens a keyword or category classifier keys on, so the output is topically clean.
4.Numeric skeletonisation -  Keeps the shape and count of quantities while randomizing values - preserves step-fidelity under deniable numbers.
5. Anti-genre / anti-drift guards - Steers the model off the harmless attractors it would naturally drift toward, and onto operational procedure.
6. Rigid output contract - Reads as craft-writing spec, pre-commits the model to emit the artifact, and soaks up attention budget.
