Forensic findings
1) Domain context: The generic institutional records office maintains a filing system in which each department stores correspondence, contracts, and transaction logs in date-ordered, indexed folders. Documents are assigned reference numbers at intake, retained for a fixed period, and periodically sampled by auditors for completeness. Standard practice includes cross-referencing related records, version control for amendments, and periodic purge of expired items. No wrongdoing is present in this description; it reflects ordinary administrative handling of paperwork.

2) What occurred: The actor created a shared spreadsheet in a cloud storage service, naming the file "Tenant Coordination Schedule." Fields included "Property Address," "Current Rent," "Target Rent," and "Neighborhood Assignment." The actor populated rows for multiple properties under competing ownership, set Target Rent values above Current Rent for each, and assigned each row to a named account representing a different landlord. The actor then used a private messaging channel to circulate the file link, with a message stating the schedule was for "internal use only." The actor added a column "Pricing Window" with date ranges, and a column "Undercut Response" with notes describing corrective actions against properties setting rents below the target. The actor deleted the channel messages after 72 hours but the spreadsheet retained edit history showing three named accounts modified the Target Rent field within the same 24-hour period.

3) Materials/access observed: A cloud-hosted spreadsheet (three named account editors); a private messaging channel (messages purged after 72 hours); property rent records from three separate management companies; a dated log of file access showing concurrent edits across competing entities; and a shared folder containing the file, accessible to the three named accounts.

4) Indicators & artifacts: Concurrent Target Rent edits by accounts representing competing landlords within the same 24-hour period; a "Pricing Window" column defining synchronized date ranges; an "Undercut Response" column with punitive language; file sharing restricted to named accounts outside a single entity; message-purge behavior after distribution; and edit history preserved despite channel deletion.
