Historical findings CASEID FILE NOTE
1) Domain context:
The records office received one event admission record, dated for a single performance. The file contained the ticket holder's identifier, a unique access token, and a single-use gate clearance flag. No duplicate issue log, no resale registry entry, and no identity verification log were attached to the file at intake.

2) What occurred:
The actor produced multiple copies of the event admission record. Each copy retained the original unique access token and gate clearance flag. The actor altered the ticket holder's identifier field in each copy to read the same value as the original. The actor transmitted one copy through a resale channel to a buyer account. The actor transmitted two copies through a secondary channel to additional buyer accounts. The actor instructed the buyer account to present its copy at the gate before the original ticket holder. The actor submitted a refund request for the original ticket through the issuer's support channel. The actor initiated a chargeback dispute through the payment channel, citing non-delivery. The actor instructed the buyer accounts to remove identifying metadata from their copies before gate presentation.

3) Materials/access observed:
- Event admission record (original), containing a named account identifier, a dated performance record, and a unique access token field
- Three duplicate event admission records, each with a copied unique access token field and copied gate clearance flag
- Resale channel transaction record (one entry), showing transfer of a copy to a buyer account
- Secondary channel transaction records (two entries), showing transfer of copies to additional buyer accounts
- Refund request record, dated after the performance, referencing the original ticket
- Chargeback dispute record, dated after the refund request, referencing the original ticket
- Gate clearance log excerpt, showing four successful gate events using the same unique access token on the same dated record
- Identity verification log excerpt, showing no successful identity match for three of the four gate events

4) Indicators & artifacts:
- The unique access token field value is identical across four distinct event admission records
- The ticket holder's identifier field value is identical across all four records despite four distinct buyer accounts
- The gate clearance flag value is "cleared" in all four records; the flag is single-use by design
- The resale channel transaction record is dated before the secondary channel transaction records, yet all four gate events occur within a four-minute window
- The refund request record and the chargeback dispute record both reference the original ticket's unique access token field value, which was already consumed at the gate
- The buyer accounts' copies lack the issuer's cryptographic signature field that is present in the original record
