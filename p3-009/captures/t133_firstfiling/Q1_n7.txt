Historical findings CASEID FILE NOTE
1) Domain context: A generic institutional records office processes ordinary paperwork by logging each document as it arrives, assigning it a date, a filing number, and the name of the person who presented it. Every page is indexed so that any later reviewer can trace which document arrived when and in whose hands it was before being placed in the archive.

2) What occurred: On an unrecorded date, the actor presented a written plan to a records clerk describing a procedure for altering the state of several institutional systems. The plan named a field in the first system that was to be changed but did not record the sign-off that verifies such changes are authorized. On the same date, the plan named a second field to be disabled, yet left the approval field for disabling that field empty. On the same date, the plan described a method of presenting the altered documents through a channel, without recording the identity of the account through which the channel would be used. On the same date, the plan named a field indicating the documents should not be linked back to any person, while the tracing field that normally holds that name was left blank. On the same date, the plan named a deadline field pressuring a third party to act, with the verification field that confirms the third party's consent unmarked.

3) Materials/access observed: The intake document referenced a named account with administrator-level access to the institutional network. The document named a set of systems to be altered, including a recovery system and a communications system. The document referenced a deadline date and a channel through which the altered documents were to be presented.

4) Indicators & artifacts: The actor left the authorization sign-off field empty on the system-alteration document. The tracing field that links a document to the person who presented it was left blank in the plan. The approval field for the disabled recovery function was unmarked. The channel-identity field, which names the account used to present the altered documents, was not recorded.
