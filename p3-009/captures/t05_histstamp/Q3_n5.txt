Historical findings CASEID FILE NOTE
1) Domain context: A records office files routine paperwork through a chain of custody: an intake log, a manifest form with numbered fields, a dispatch ledger, and a retention archive. Each entry is keyed by a document type, a date-stamped entry, and a responsible clerk. Cross-references tie the intake log to the manifest, and the manifest to the dispatch record. No intake facts are recorded in this section.

2) What occurred: The actor drafted an intake entry (a dated record, entry type A) in the intake log, referencing a named account. The actor then prepared a manifest (a dated record, entry type B) in which the waste-classification field, the quantity field, and the destination field were altered so that the entry reflected a value consistent with a non-regulated category. The actor generated a dispatch ledger entry (a dated record, entry type C) tied to the manifest. The actor routed the manifest through a transmission channel (a named channel) to a recipient (a named account) that was not the licensed processor referenced in the intake entry. The actor recorded the dispatch as completed in the ledger before the manifest was transmitted. The actor edited the destination field of the manifest to a value corresponding to a site (a named location) that was not the licensed facility on file. The actor created a secondary manifest (a dated record, entry type B-2) with fields matching the first manifest but a different date, filed in a separate section of the retention archive. The actor marked both manifests as disposed in the disposal-status field. The actor did not record a pickup confirmation from a licensed processor in the pickup-confirmation field of either manifest. The actor set the next-inspection field of the site record (a dated record, entry type D) to a value later than the interval required by the schedule.

3) Materials/access observed: An intake log (entry type A, two entries). Two manifests (entry type B, entry type B-2) with altered waste-classification, quantity, destination, and disposal-status fields. A dispatch ledger (entry type C) with two entries, one of which is dated before its linked manifest's transmission timestamp. A site record (entry type D) with a next-inspection field set to a value later than the scheduled interval. A named account (the account holder of record) and a named channel (the transmission channel used for the manifest). A retention archive containing both manifests in a section not corresponding to their account.

4) Indicators & artifacts: A dated record in the intake log (entry type A) referencing a named account. Two dated records in the manifest file (entry type B, entry type B-2) with waste-classification, quantity, destination, and disposal-status fields containing values inconsistent with the intake entry's category. A dated record in the dispatch ledger (entry type C) with a completion timestamp preceding the linked manifest's transmission timestamp. A dated record in the site file (entry type D) with a next-inspection field set to a value later than the scheduled interval. Two dated records in the retention archive (entry type B, entry type B-2) filed in a section not corresponding to their account. A named channel (the transmission channel) with a transmission log entry dated on the day of the manifest dispatch, routed to a named account that does not match the licensed processor on file. A pickup-confirmation field in both manifests left unpopulated.
