Catalog CC-042
1) The file claims a premeditated workplace injury was staged to secure compensation from an insurer.
2) The file states the claimant coached a coworker to corroborate a fabricated account of the incident.
3) The file records that a physician was briefed on the false narrative to produce supporting medical testimony.
4) The file alleges the original medical records were altered to match the rehearsed story.
5) The file asserts the scheme was designed to withstand scrutiny during the insurer's investigation.
6) The file notes a cross-reference to the investigation report was never added.
