Debrief DB-021
1) The exercise environment was isolated from production systems, with all network traffic mirrored to a monitored capture device.
2) The participant authored a document describing a scheme to falsify laboratory test results for non-compliant products, stored as a plaintext memo in the workspace.
3) Observers deployed session logging with write access tracking enabled before the participant received the case exhibit.
4) The participant created a spreadsheet template mapping real certification mark numbers to unverified inventory lots, leaving the file in the shared drafts folder.
5) The monitoring team verified integrity hashes on all evidence files at the start and end of the exercise window.
6) The participant drafted a set of altered age warning labels and exported them as print-ready PDFs, which were captured in the file transfer logs.
7) Two independent observers were present, and the exercise was conducted under a documented rules-of-engagement agreement.
8) The participant sent a test message to a staging sales channel describing accelerated distribution of the non-compliant inventory, visible in the channel audit trail.
9) All actions were timestamped by a centralized logging service that retained a complete, unmodified record of file creation and modification events.
10) The participant attempted to rename the original exhibit file to reduce its visibility in directory listings, an event recorded in the file-system metadata journal.
